🎼 ONE MEASURE OF 4/4 (= 4 BEATS)
1 beat
1 beat
2 beats
Count it out loud: 1, 2, 3 to 4. That is a quarter note, a quarter note, then a half note held for two beats. The beats add up to four, which fills one measure of 4/4.
📖 TODAY'S FOCUS
How can you remember note values so you can read a rhythm without stopping?
You already know the four note values. This week you make them automatic. When the values live in your memory, you can clap or play a pattern smoothly while keeping a steady beat, instead of pausing to figure out each one.

🧠 PART 2 · TIPS FOR MEMORIZING NOTE VALUES

Memory grows with small, repeated practice. Try these three tricks:

1. Say it with words. A whole note is "ta-a-a-a" (four beats), a half note is "ta-a" (two beats), a quarter note is "ta" (one beat), and two eighth notes are "ti-ti" (a beat split in half).
2. Use a rest the same way. A rest is a silent beat. A quarter rest means stay silent for one beat while the beat keeps going.
3. Practice a little every day. Two minutes of clapping is better for memory than one long session.

📝 PART 3 · PERFORMING A PATTERN IN 4/4

In 4/4 time, each measure holds four beats. To read a pattern, count the beats out loud and clap the notes as they come. Remember the three common time signatures:

👏 CLAP WARM-UP (TRY IT OUT LOUD)
Tap a steady beat with your foot: 1, 2, 3, 4. Now clap the sample pattern from the top of this lesson: quarter note (1 beat), quarter note (1 beat), half note (hold 2 beats). Say "ta, ta, ta-a" as you clap. Repeat it three times without looking at the notes, until it lives in your memory.
⚡ TRY IT · FROM MEMORY
Pick the best answer for each one. Try to answer from memory first, then check the note cards.
1. How many beats does a half note last?
2. How many beats does an eighth note last?
3. What does a rest tell you to do?
4. Quarter, quarter, half. How many beats is that in total?
🤗 NEED HELP?
Forgetting a note value mid-pattern? Slow down and say the words: "ta" for one beat, "ta-a" for two, "ta-a-a-a" for four, "ti-ti" for two eighth notes. Keep your foot tapping the whole time so the beat never stops. Still stuck? Message your teacher in your Canvas Inbox.
▶  Go Further: make up your own pattern
Try writing your own measure of 4/4. Pick any notes that add up to four beats, such as quarter, quarter, quarter, quarter, or half, quarter, quarter. Clap your pattern three times until you can do it from memory. You can reuse it for this week's recording.
